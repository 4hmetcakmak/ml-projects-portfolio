# California Housing – Linear Baseline vs. Deep Neural Network

Predicts median house values in California with TensorFlow / Keras.

- Z-score normalization of features and label.
- Feature layer with bucketized and crossed features (latitude × longitude).
- Linear regression baseline vs. deep neural network, with experiments on network topology and regularization.

**Data:** California housing train/test CSVs from the Google Machine Learning Crash Course (loaded from URL).

**TR:** California konut fiyatlarının tahmini. Doğrusal regresyon ile derin sinir ağı karşılaştırması, özellik çaprazlama ve ağ topolojisi denemeleri.
