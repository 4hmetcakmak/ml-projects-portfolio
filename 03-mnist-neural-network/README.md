# MNIST Multi-Class Classification with a Neural Network

Handwritten digit recognition (10 classes) with a fully connected neural network in TensorFlow / Keras.

- Normalized pixel values to the 0–1 range.
- Systematically compared the number of hidden layers, nodes per layer (e.g. 20, 30, 30-15, 30-25, 40-25) and dropout rates.
- Final model reaches **~98 % test accuracy**.

**TR:** Elle yazılmış rakamların (MNIST) yapay sinir ağı ile sınıflandırılması. Katman, nöron sayısı ve dropout denemeleri sonucunda yaklaşık %98 test doğruluğu elde edildi.
